# Zed

The global tasks expose the same `qmake-workflow` commands used by Neovim and
the terminal. They run on the remote machine when the project is opened through
Zed's native Remote Development support.

Open the Remote Projects dialog with `Ctrl+Alt+Shift+O`, choose **Connect New
Server**, and enter an SSH destination from your machine-local
`~/.ssh/config`. Zed installs its matching headless server and runs language
servers, terminals, and tasks on that host.

The `modify_private_settings.json` chezmoi modifier preserves existing settings
and SSH connections while enabling semantic tokens and auto-installing the Lua,
NeoCMake, Make, QML, and Pkl language extensions. Python, Rust, C, and C++ are
built into Zed. The qmake file types use Make highlighting because Zed has no
qmake grammar or language server; clangd still handles the C/C++ source through
`build/compile_commands.json` generated by `qmake-workflow compdb`.

Do not install the third-party `remote-ssh` extension for this workflow.
